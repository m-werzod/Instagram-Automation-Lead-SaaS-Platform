## 4. "Insufficient developer role" — root cause

Meta answers `error=access_denied&error_description=Insufficient developer role` when an Instagram account
that holds **no role on the app** tries to authorize an app in **Development Mode**. The platform's OAuth
request is correct; nothing the account owner does can get past it. Only the app owner can, by either

1. adding the account as an **Instagram Tester** (App Dashboard → App roles → Roles → Add people →
   Instagram Tester), after which the owner accepts the invite in Instagram → Settings → Website
   permissions → Tester invites; or
2. taking the app **Live** after App Review for `instagram_business_basic`, `…_manage_messages`,
   `…_manage_comments` (plus `…_content_publish` for publishing).

Code-level changes made in this upgrade: preflight in `/api/meta/config-status` that flags an Instagram
app id identical to the Facebook app id, a non-HTTPS redirect, and missing credentials; a Development-Mode
checklist card on `/instagram`; the tester steps on both the admin page and the invited owner's page.
Everything else is Meta App Dashboard configuration — listed in the final report.
